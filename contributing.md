# Contribution Guidelines

Please follow [sindresorhus/awesome](https://github.com/sindresorhus/awesome/blob/main/awesome.md).

## Quality bar

- Curation, not a collection. Only list something you would personally recommend.
- Must have a primary source: official docs, the project GitHub repo, or an `https://x.ai/bot/<id>` share link.
- Do not add other directories, marketplaces, or list sites.
- No screenshot-only posts, unverified revenue claims, or archived/unmaintained repos.
- One job per bot. Reject kitchen-sink prompts.
- Prefer draft-and-wait bots. Flag anything that auto-posts, auto-pays, or messages outsiders.
- Search the list first. No duplicates.
- Do not invent install counts, prices, or share links.

## Format

```md
- [Name](url) - Short description of what it does and why it is useful.
```

- Add to the **bottom** of the relevant section.
- Description is sentence case, not a marketing tagline, not title case.
- Start with a capital letter, end with a period.
- Link the repo or official share page only. No aggregator or directory URLs.
- One suggestion per pull request.
- Grammar and Markdown must be clean.

## Pull request title

```
Add Name
```

or
